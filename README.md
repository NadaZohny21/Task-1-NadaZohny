# Data Cleaning Project - DecodeLabs Internship

## What this project does
Cleans a raw sales dataset by handling missing values, 
removing duplicates, and verifying data formats.

## What I fixed
- Filled 309 missing CouponCode values with "No data"
- Verified zero duplicate Order IDs
- Verified all dates are correctly formatted

## Tools used
- Microsoft Excel

## Dataset
1200 rows of sales order data with 14 columns including
OrderID, Date, Product, Quantity, Price and more.
